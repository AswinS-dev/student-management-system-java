# Student Management System

A console-based Student Management System developed using Core Java.

## Features

* Add student
* View all students
* Update student details
* Delete student
* Search student by ID or name
* Show total number of students
* Calculate class average
* Find topper
* Grade calculation
* Input validation
* Exception handling
* File handling for data persistence
* Duplicate student ID validation

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Exception Handling
* File Handling
* Command Line Interface (CLI)

## How to Run

### 1. Compile the Java files

```bash
javac *.java
```

### 2. Run the application

```bash
java StudentManagementSystem
```

## Data Persistence

Student records are stored in a local text file using Java File Handling.

The `students.txt` file is generated automatically when student data is saved.
